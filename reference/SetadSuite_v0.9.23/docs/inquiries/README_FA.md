# Setadiran Manager — نسخه آزمایشی ویندوز

این نرم‌افزار برای **خواندن فهرست نیازهای قابل‌دسترسی خودتان در سایت ستاد ایران، انتخاب چند نیاز و ذخیره پیوست‌های مجاز آن‌ها** طراحی شده است.

## امکانات نسخه فعلی

- رابط فارسی راست‌به‌چپ (Qt) با فونت وزیرمتن داخلی؛ جست‌وجو و فیلتر بر اساس استان، نوع، دستگاه و گروه
- باز شدن جزئیات هر نیاز درست زیر ردیف همان نیاز، با فهرست پیوست‌ها
- خواندن ۱، ۵ یا حداکثر ۲۰ صفحه از فهرست بازشده در مرورگر (تعداد واقعی صفحات و صفحه‌بندی سایت تعیین‌کننده است)
- انتخاب چندتایی از جدول با تیک ستون «انتخاب»
- دریافت خودکار فهرست مدارک هر نیاز و استفاده از لینک دانلود در مرورگر واقعی
- ساخت پوشه با **شماره نیاز** و ذخیره همه مدارک مجاز با نام اصلی
- ثبت شناسه هر فایل در `.download_manifest.json` برای جلوگیری از دانلود دوباره
- گزارش موارد فاقد پیوست، بدون مجوز، ناموفق یا تکمیل‌شده
- خروجی CSV اطلاعات جدول

## نصب در Windows 10/11

۱. Python **3.11 یا جدیدتر** را از سایت رسمی Python نصب کنید. هنگام نصب، گزینه Add Python to PATH را فعال کنید.

۲. محتوای ZIP را در یک پوشه از حالت فشرده خارج کنید.

۳. `setup_windows.bat` را یک‌بار اجرا کنید و منتظر نصب کتابخانه‌ها بمانید. نصب اینترنت لازم دارد.

۴. `run_windows.bat` را اجرا کنید. Microsoft Edge پیش‌فرض است؛ برنامه در صورت نبودن Edge، Chrome یا Chromium را امتحان می‌کند. در صورت نبودن این مرورگرها، دستور `.venv\Scripts\python.exe -m playwright install chromium` را اجرا کنید.

۵. در برنامه روی **باز کردن مرورگر / ورود** کلیک کنید و **خودتان** ورود به سامانه را تکمیل کنید؛ برنامه رمز عبور نمی‌خواهد.

۶. در همان مرورگر صفحه فهرست نیازها را باز کنید. در برنامه تعداد صفحات (برای شروع **۱**) را انتخاب کنید و **دریافت / به‌روزرسانی نیازها** را بزنید.

۷. شماره نیازهای موردنظر را علامت بزنید، پوشه مقصد را انتخاب کنید و **دانلود پیوست‌های انتخاب‌شده** را بزنید.

## محل فایل‌ها

پوشه پیش‌فرض در ویندوز:

`%LOCALAPPDATA%\SetadiranManager\Setadiran`

مثال:

```text
Setadiran/
  1105093179000506/
    شرایط.pdf
    تصویر.jpg
    .download_manifest.json
  1105094376000017/
    شرایط عمومی استعلام.pdf
```

پروفایل مرورگر (نشست ورود) به‌صورت محلی در `%LOCALAPPDATA%\SetadiranManager\browser-profile` ذخیره می‌شود؛ رمز عبور را داخل نرم‌افزار وارد نمی‌کنید. این پوشه را مانند یک نشست حساس مرورگر خصوصی نگه دارید.

## وضعیت آزمایشی و محدودیت‌ها

**این نسخه هنوز روی سایت زنده از این محیط اجرا نشده**؛ دسترسی به حساب کاربری شما نداریم. کد بر اساس HTML، توابع JavaScript و آزمایش‌های مرورگری که در گفتگو ارائه کردید تهیه شده است. خواندن جدول اصلی، دریافت صفحه جزئیات، پیدا کردن شناسه پیوست و دانلود مستقیم یک فایل قبلاً در مرورگر شما آزمایش شده؛ اتصال یکپارچه و اجرای دانلود با Playwright هنوز نیاز به آزمون روی رایانه شما دارد.

- لایه امنیتی F5 ممکن است بعضی دانلودها را متوقف کند یا به‌جای فایل HTML برگرداند. برنامه **هیچ کپچا یا کنترل امنیتی را دور نمی‌زند**؛ دانلود ناموفق را ثبت می‌کند.
- فقط به پیوست‌هایی دسترسی می‌دهد که خود سایت اجازه نمایش آن‌ها را تأیید کند.
- در زمان بروزرسانی یا دانلود، مرورگر کنترل‌شده توسط برنامه را دستکاری نکنید.
- اگر در سایت ترتیب ستون‌ها، اسامی توابع یا آدرس‌ها عوض شوند، ممکن است نیاز به اصلاح برنامه باشد.
- اگر Excel شماره نیاز ۱۶ رقمی CSV را به عدد تبدیل کند، احتمال از دست رفتن دقت وجود دارد؛ CSV را با **ستون شماره نیاز از نوع Text** وارد Excel کنید. در پوشه‌ها شماره‌ها به‌صورت دقیق ذخیره می‌شوند.
- اگر سایت برای دانلود بعضی فایل‌ها تأییدیه یا مجوز اضافی بخواهد، باید از روال رسمی سایت استفاده شود.

## ساخت EXE روی ویندوز

پس از نصب پیش‌نیازها، `build_exe_windows.bat` را اجرا کنید. پوشه زیر ساخته می‌شود:

`dist\SetadiranManager\SetadiranManager.exe`

فایل EXE **همراه پوشه کتابخانه‌های کنارش** باید منتقل شود (نسخه onedir). این بسته ZIP حاوی فایل EXE ویندوز نیست؛ چون در محیط لینوکس ساخته شده و build ویندوز باید روی ویندوز اجرا شود. ساخته‌شدن EXE روی رایانه مقصد نیز باید بررسی شود.

## حفظ اطلاعات کاربری

- کوکی، رمز عبور یا توکن نشست را برای کسی نفرستید.
- برنامه وارد API مخفی یا درخواست ساختگی با کوکی‌های استخراج‌شده نمی‌شود؛ از مرورگر کنترل‌شده خودتان برای نمایش و دانلود مجاز استفاده می‌کند.
- با محدودیت‌های دسترسی، نرخ درخواست و مقررات سامانه مطابقت داشته باشید.
