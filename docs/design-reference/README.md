# BOMS design reference (for v0.10.0)

Copy this folder into the repo as `docs/design-reference/`.

Each mockup is a standalone HTML file (inline styles: exact colours, sizes, spacing) with a PNG screenshot at 1440 px.

- Dark, advanced series (primary reference): ProToday, ProCase, ProListings, ProTriage, ProFinance, ProTender, ProShipment, ProReview, ProAISettings, ProCommand, ProParty.
- Light series (palette and tone of the light theme): Main, Case, Listings, Finance.
- Style reference only, modules not built in v0.10.0: ProAssistant, ProLegal, ProComms, ProDiscovery.

All names, numbers and sentences in the mockups are samples. The screenshots here were rendered without the web fonts; the HTML names the intended fonts (Vazirmatn, Noto Naskh Arabic).
